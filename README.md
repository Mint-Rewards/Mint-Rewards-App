# Mint Rewards — mobile app

The Expo client for Mint Rewards, a consumer recycling-rewards app for Pakistan.
Users register, give their home location, have waste collected, earn points, and
redeem those points for deals from partner brands.

- **Backend:** [`Mint-Rewards-Backend`](https://github.com/Mint-Rewards/Mint-Rewards-Backend) (Next.js on Vercel)
- **Stack:** Expo SDK 56 · React Native 0.85.3 · expo-router v6 · Zustand · TypeScript
- **Current version:** `2.2.1` (set in `app.config.js`)

## Prerequisites

- Node 20+, and `npx eas-cli` (no global install needed)
- An account on the `mint-rewards` Expo organisation
- Xcode (iOS) and/or Android Studio, if you want to build locally

## Setup

```bash
npm install            # also applies patches/ via patch-package — required for Android
cp .env.example .env   # then fill in real values
```

Every key in `.env.example` is documented in place. `config/env.ts` validates
them at startup and throws with all missing keys listed at once, so if you get
that error it is telling you exactly what to fill in.

## Running

**Expo Go will not work.** This app has native modules Expo Go does not bundle —
Google Sign-In, Firebase, maps, PDF printing, secure storage. You need a
development build:

```bash
# once, per platform
npx eas-cli build --profile development --platform ios      # device
npx eas-cli build --profile development --platform android  # device
npx eas-cli build --profile simulator   --platform ios      # iOS simulator
```

Install the artifact, then start Metro against it:

```bash
npx expo start          # add --clear after changing .env or app.config.js
```

To build and run natively on your own machine instead:

```bash
npm run ios
npm run android
```

## Commands

| Command | Does |
|---|---|
| `npx expo start` | Metro dev server |
| `npm test` | Jest — baseline is 44 suites / 728 tests passing |
| `npm run lint` | ESLint — accepted baseline is 29 problems, not zero |
| `npm run ios` / `npm run android` | Local prebuild + native build |
| `npx expo config --type public` | Resolve `app.config.js`; the fastest way to debug config errors |

## Layout

```
app/          expo-router routes (file-based, typed routes on)
components/   shared UI, incl. LocationGate, UpdateGate, ForceUpdateScreen
store/        store.ts — the single Zustand store (4 slices)
utils/        non-React logic: api, session, auth, location stack, versionGate
hooks/        reusable hooks
config/       env.ts — the only module that reads environment config
firebase/     Google services files (prod + dev, iOS + Android)
patches/      patch-package patches, applied on postinstall
docs/         handoff, release notes, design specs
__tests__/    Jest suites
```

`android/` and `ios/` are gitignored — they are generated by `expo prebuild`
from `app.config.js`. **Never hand-edit them**; changes are wiped on the next
prebuild. Native configuration goes in `app.config.js`.
